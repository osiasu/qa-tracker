Cloud sync — Supabase (free)
Store test cases in your own Supabase project so the whole team shares the same data in real time.
1Sign up free at supabase.com → create a project.
2Open the SQL Editor and run the setup query below once to create the table.
3Go to Project Settings → API → copy the Project URL, anon key, and service_role key.
4Paste below and click Connect. Share the Project URL + anon key with viewers.
▶ Show one-time SQL setup 
create table if not exists qa_tracker_data (
  id serial primary key,
  name text not null default 'Unnamed',
  description text default '',
  cases jsonb not null default '[]',
  updated_at timestamptz default now()
);
insert into qa_tracker_data (name, description, cases)
  values ('My QA Tracker', 'Default dataset', '[]')
  on conflict do nothing;
alter table qa_tracker_data enable row level security;
create policy "public_read" on qa_tracker_data
  for select using (true);

Export CSV
Export test cases to a CSV file for reporting, backup, or sharing with stakeholders.
1Apply filters (module, priority, status, etc.) to narrow down which cases to export — or leave all filters open to export everything.
2Click the Export CSV button in the toolbar. If filters are active, the button changes to Export filtered — it will only export the visible subset.
3The CSV file downloads automatically to your computer. It includes a summary section with pass rate statistics at the bottom.
CSV contents: Date, Time, Test ID, Name, Scenario, Steps, Module, Priority, Type, Environment, Input Data, Expected, Actual, Status, Notes, Evidence, Credentials, Logs
